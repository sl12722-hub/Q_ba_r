# Q_ba_r

This repository contains the `agentic-alpha-research` Codex Skill release:

- `agentic-alpha-research-v6.0.0-release-20260903/` is the release package.
- The package provides research workflow instructions, deterministic audit scripts,
  references, and regression tests for local alpha-factor/model research.
- It does not include market data, trained models, private factor outputs, or a
  standalone backtesting engine.

To install it as a Codex Skill, copy the contents of the release package into:

```text
%USERPROFILE%\.codex\skills\agentic-alpha-research
```

The installed skill directory must contain `SKILL.md` at its top level.
